# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report vulnerabilities through our bug bounty program on Immunefi:
https://immunefi.com/bug-bounty/ens/

If you cannot use Immunefi, email security@ens.domains.

Please include:
- Affected contract(s), commit hash, and network
- Description of the issue and its impact
- Steps to reproduce or a proof of concept

## Scope

In scope: smart contracts in this repository as deployed on Ethereum mainnet
(see the Immunefi page for the authoritative asset list).

Out of scope: issues already reported or publicly disclosed, third-party
contracts and integrations, and frontend/UI issues.
